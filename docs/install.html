setup

Install the CLI, choose a root, then let launchd do the routine work.

User-owned mounts run without sudo. The system cache helper needs sudo because it manages paths under /Library/Developer.

Install the CLI

Install macos-offload from the public Homebrew tap. The formula builds from the tagged source release. 

brew install rudironsoni/tap/macos-offload
macos-offload version

If you prefer to tap first, run brew tap rudironsoni/tap, then brew install macos-offload.

Pick a root

Choose the external volume yourself. The tool will not pick one for you. 

export MACOS_OFFLOAD_ROOT="/Volumes/YourExternalVolume"

Preview user changes

macos-offload repair \
  --root "$MACOS_OFFLOAD_ROOT" \
  --home "$HOME" \
  --scope user \
  --install-shims \
  --dry-run

Install user-owned pieces

macos-offload repair \
  --root "$MACOS_OFFLOAD_ROOT" \
  --home "$HOME" \
  --scope user \
  --install-shims \
  --load

This installs the user LaunchAgent and optional shims. It does not write root-owned files.

Install the system helper

Run the doctor

macos-offload doctor \
  --root "$MACOS_OFFLOAD_ROOT" \
  --require-shims \
  --strict

Use APFS mount mode

For direct mounts at the Apple paths, use the mounts group: 

macos-offload mounts install --root "$MACOS_OFFLOAD_ROOT" --home "$HOME" --scope user --load
macos-offload mounts status --root "$MACOS_OFFLOAD_ROOT" --home "$HOME" --scope all
Keep the external volume mounted before opening Xcode or Simulator. The wrappers fail closed while it is absent, and the user agent reconciles automatically when the configured volume returns.
